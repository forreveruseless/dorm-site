# Навигация по общежитию — версия 6

Изменения:

- запись комнаты в календаре теперь отображается в формате:
  - `L-3.5-6`
  - `R-8-2`
- формат означает: крыло — этаж — номер комнаты;
- запись времени в календаре стала кликабельной;
- при нажатии на событие сайт:
  - открывает нужное крыло;
  - переходит на нужный этаж/блок;
  - открывает страницу блока;
  - подсвечивает нужную комнату;
  - прокручивает страницу к этой комнате;
- старые сохранённые события тоже отображаются в новом формате автоматически.

## Запуск
Открой `index.html` в браузере.

# Навигация по общежитию — версия 7 (общая онлайн-база)

В этой версии локальное хранение заменено на Supabase.

## Что теперь хранится в общей базе

- заметки по каждой комнате;
- цвет комнаты;
- события общего календаря;
- дата и временной промежуток;
- привязка события к крылу, этажу, блоку и комнате.

Изменение, сделанное на одном устройстве, можно увидеть на другом устройстве.
Страница автоматически обновляет открытый блок/календарь примерно раз в 20 секунд.

## Supabase

Проект уже подключён в `app.js` через:
- Project URL;
- Publishable key.

В браузерном сайте используется только Publishable key. Secret/service_role ключ в сайт добавлять нельзя.

## Перед публикацией

В Supabase должны существовать таблицы:

- `room_data`
- `calendar_events`

и должны быть включены RLS-политики, которые ранее были созданы через SQL Editor.

## Как обновить сайт на GitHub Pages

1. Распакуй архив.
2. В репозитории `dorm-site` замени старые `index.html`, `styles.css`, `app.js` новыми.
3. Закоммить изменения.
4. GitHub Pages обновится автоматически через несколько минут.

## Важно

Старые записи, которые раньше находились только в `localStorage`, автоматически в Supabase не переносятся.
Новые изменения уже сохраняются в общую онлайн-базу.

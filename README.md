# Навигация по общежитию — версия 8: «Связи»

## Что появилось

В верхней панели теперь 3 вкладки:

- Общага
- Календарь
- Связи

### Карта связей

Вкладка «Связи» показывает все 256 комнат как интерактивный граф.

Типы связей:

- **Близкие** — зелёная толстая линия, комнаты сильнее притягиваются друг к другу.
- **Друзья** — жёлтая линия средней толщины и средней силы.
- **Знакомые** — красная тонкая линия, комнаты находятся свободнее и дальше.

Карта использует force-directed layout: группы комнат с большим количеством сильных связей автоматически собираются ближе.

Карту можно:

- двигать;
- приближать/отдалять;
- перетаскивать отдельные комнаты;
- сбрасывать к исходному масштабу.

### Как создать связь

**Способ 1**

1. Общага.
2. Открыть комнату.
3. Нажать «Новая связь».
4. Выбрать тип связи.
5. В мини-карте выбрать крыло, этаж и вторую комнату.
6. Нажать «Создать связь».

**Способ 2**

1. Открыть вкладку «Связи».
2. Нажать на точку-комнату.
3. Появится то же окно мини-карты.
4. Выбрать вторую комнату и тип связи.

## ВАЖНО: один дополнительный шаг Supabase

До загрузки версии 8 на GitHub открой:

**Supabase → SQL Editor → New query**

Открой файл:

`SUPABASE_RELATIONS_SETUP.sql`

Скопируй весь код, вставь в SQL Editor и нажми **Run**.

После этого связи будут храниться в общей базе и будут одинаковыми у всех пользователей.
